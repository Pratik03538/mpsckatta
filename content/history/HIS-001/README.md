# HIS-001 : प्रागैतिहासिक काळ

## अभ्यास उद्दिष्टे
या घटकानंतर विद्यार्थी प्रागैतिहासिक, आद्य-ऐतिहासिक व ऐतिहासिक काळातील फरक स्पष्ट करू शकेल; पुरातत्त्वीय पुराव्यांचे महत्त्व समजू शकेल; पुरापाषाण, मध्यपाषाण व नवपाषाण या कालखंडांची वैशिष्ट्ये तुलना करू शकेल; आणि महाराष्ट्रासह भारतीय उपखंडातील महत्त्वाची स्थळे ओळखू शकेल.

## अभ्यासक्रमाचा क्रम
1. संकल्पना व पुरावे
2. पुरापाषाण : खालचा, मधला, वरचा
3. मध्यपाषाण व सूक्ष्माश्म
4. नवपाषाण व अन्नउत्पादन
5. भारतीय उपखंडातील स्थळे
6. महाराष्ट्रातील महत्त्वाचे पुरावे
7. कालखंडांची तुलना व परीक्षाभिमुख उजळणी

**सूचना:** कालमर्यादा प्रदेशानुसार बदलतात. एका प्रदेशातील कालविभागणी संपूर्ण भारतीय उपखंडाला तशीच लागू करू नये.
