# HIS-006 — बौद्ध धर्म

## अभ्यास उद्दिष्टे
गौतम बुद्धांचे जीवन, बौद्ध धर्माची मूलतत्त्वे, चार आर्यसत्ये, अष्टांगिक मार्ग, बौद्ध संघ, संगीती, त्रिपिटक, पंथ आणि प्रसार समजून घेणे.

## अभ्यासक्रम
1. गौतम बुद्धांचे जीवन व चार प्रमुख स्थळे
2. चार आर्यसत्ये, मध्यम मार्ग व अष्टांगिक मार्ग
3. प्रतीत्यसमुत्पाद, अनित्य, अनात्म व निर्वाण
4. संघ, उपासक व भिक्षुणी संघ
5. बौद्ध संगीती व त्रिपिटक
6. थेरवाद, महायान व वज्रयान
7. बौद्ध धर्माचा प्रसार, कला व स्थापत्य
