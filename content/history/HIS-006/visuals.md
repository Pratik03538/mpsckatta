# HIS-006 — Visual Revision Pack : बौद्ध धर्म

## 1. बुद्धांच्या जीवनातील चार स्थळे

| घटना | स्थळ |
|---|---|
| जन्म | लुंबिनी |
| बोधीप्राप्ती | बोधगया |
| पहिला उपदेश | सारनाथ |
| महापरिनिर्वाण | कुशीनगर |

## 2. चार आर्यसत्ये — समस्या ते मार्ग

```text
दुःख
 ↓
दुःखसमुदय (तृष्णा)
 ↓
दुःखनिरोध (निर्वाण)
 ↓
दुःखनिरोधगामिनी प्रतिपदा (अष्टांगिक मार्ग)
```

## 3. आर्य अष्टांगिक मार्ग

| प्रज्ञा | शील | समाधी |
|---|---|---|
| सम्यक दृष्टि | सम्यक वाचा | सम्यक व्यायाम |
| सम्यक संकल्प | सम्यक कर्म | सम्यक स्मृती |
|  | सम्यक आजीविका | सम्यक समाधी |

## 4. त्रिपिटक

```text
त्रिपिटक
├─ विनयपिटक   → संघशिस्त
├─ सुत्तपिटक   → उपदेश व संवाद
└─ अभिधम्मपिटक → तात्त्विक विश्लेषण
```

## 5. संगीतींची पारंपरिक रूपरेषा

| संगीती | पारंपरिक स्थळ | लक्षात ठेवण्याचा संदर्भ |
|---|---|---|
| पहिली | राजगृह | अजातशत्रू |
| दुसरी | वैशाली | विनय मतभेद |
| तिसरी | पाटलीपुत्र | अशोक |
| चौथी | काश्मीर/कुंडलवन | कनिष्काशी संबंधित काही परंपरा |

**टीप:** संगीतींचा क्रम/तपशील सर्व पंथांत समान नाही.

## 7. स्थापत्य — ओळख

| प्रकार | उपयोग |
|---|---|
