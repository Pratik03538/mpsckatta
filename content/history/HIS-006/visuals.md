# HIS-006 — दृश्याधारित उजळणी

## बुद्धांच्या जीवनातील चार स्थळे
| घटना | स्थळ |
|---|---|
| जन्म | लुंबिनी |
| बोधीप्राप्ती | बोधगया |
| पहिला उपदेश | सारनाथ |
| महापरिनिर्वाण | कुशीनगर |

## चार आर्यसत्ये
| सत्य | मुख्य आशय |
|---|---|
| दुःख | जीवनातील असमाधान/दुःख |
| दुःखसमुदय | तृष्णेमुळे दुःखाची उत्पत्ती |
| दुःखनिरोध | तृष्णेचा निरोध शक्य |
| दुःखनिरोधगामिनी प्रतिपदा | अष्टांगिक मार्ग |

## अष्टांगिक मार्ग
सम्यक दृष्टी → सम्यक संकल्प → सम्यक वाचा → सम्यक कर्म → सम्यक आजीविका → सम्यक व्यायाम → सम्यक स्मृती → सम्यक समाधी

## त्रिपिटक
| पिटक | आशय |
|---|---|
| विनय | संघनियम |
| सुत्त | उपदेश व संवाद |
| अभिधम्म | तत्त्वज्ञानात्मक विश्लेषण |

## संगीती — परंपरागत स्थान
| संगीती | स्थान | परंपरेतील संदर्भ |
|---|---|---|
| पहिली | राजगृह | अजातशत्रूशी संबंधित |
| दुसरी | वैशाली | विनयविषयक मतभेद |
| तिसरी | पाटलीपुत्र | अशोककालीन थेरवादी परंपरा |
| चौथी | काश्मीर/कुंडलवन | कनिष्काशी संबंधित काही परंपरा |

## प्रमुख प्रवाह
थेरवाद — पाली परंपरा; महायान — बोधिसत्त्व आदर्श; वज्रयान — मंत्र, मंडल व तांत्रिक साधना.

**स्रोतटीप:** संगीतींचा क्रम व तपशील विविध बौद्ध परंपरांत भिन्न आहेत.
