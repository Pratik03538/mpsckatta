# HIS-002 — दृश्याधारित अभ्यास

## 1. कालरेषा

```text
प्रारंभिक हडप्पा              परिपक्व हडप्पा                उत्तरहडप्पा
इ.स.पू. ~3300 ───── ~2600 ───────────── ~1900 ───────── ~1300
प्रादेशिक वस्ती               नगरनियोजनाचा उत्कर्ष          प्रादेशिक रूपांतरे
```

तारखा साधारण आहेत; प्रदेशानुसार टप्पे आच्छादित होऊ शकतात.

## 2. हडप्पा संस्कृतीचा व्यापक विस्तार

```text
उत्तर : जम्मू / हरियाणा परिसर
          │
पश्चिम : बलुचिस्तान — सिंध — पंजाब
          │
पूर्व : पश्चिम उत्तर प्रदेश
          │
दक्षिण : गुजरात — कच्छ
```

## 3. स्थळे आणि वैशिष्ट्ये — स्मरण नकाशा

| स्थळ | प्रदेश | की-वर्ड |
|---|---|---|
| हडप्पा | पंजाब, पाकिस्तान | नामकरण, समाधी |
| मोहेंजोदडो | सिंध, पाकिस्तान | विशाल स्नानगृह |
| धोलावीरा | कच्छ, गुजरात | जलव्यवस्थापन |
| लोथल | गुजरात | मणीउद्योग, गोदीसदृश रचना |
| कालीबंगन | राजस्थान | नांगरलेले शेत |
| राखीगढी | हरियाणा | मोठे स्थळसमूह |
| बनावली | हरियाणा | प्रारंभिक + परिपक्व स्तर |
| चन्हुदडो | सिंध, पाकिस्तान | हस्तव्यवसाय, मणी |

## 4. नगररचनेचा साधा आराखडा

```text
        मुख्य रस्ता
════════════════════════════
   │ घर │   │ घर │   │ घर │
   │    │   │    │   │    │
───┴────┴───┴────┴───┴────┴───
     झाकलेला नाला / जलनिस्सारण
════════════════════════════
   │ सार्वजनिक/कारागिरी क्षेत्र │
════════════════════════════
```

हा संकल्पनात्मक आराखडा आहे; प्रत्येक हडप्पा शहराचा प्रत्यक्ष नकाशा असा नव्हता.

## 5. अर्थव्यवस्थेचे परस्परसंबंध

```text
शेती ─────┐
पशुपालन ─┼──> अन्न व कच्चा माल ──> कारागिरी
नैसर्गिक ─┘                              │
संसाधने                                  ▼
                                    व्यापार/विनिमय
                                         │
                                         ▼
                                  वजन-मापे व शिक्के
```

## 6. स्थळ-पुरावा जुळवा

- मोहेंजोदडो → विशाल स्नानगृह; कांस्य नर्तकी; दाढीवाला पुरुषमूर्ती.
- धोलावीरा → जलाशय, पाणी व्यवस्थापन, वैशिष्ट्यपूर्ण नगररचना.
- लोथल → मणीउद्योग; गोदीसदृश जलरचना.
- कालीबंगन → नांगरलेल्या शेताचा पुरावा.
- हडप्पा → नामकरणाशी संबंधित प्रमुख स्थळ.

## 7. ऱ्हासाचे बहुकारणी मॉडेल

```text
हवामानातील बदल ─┐
नदीप्रवाह बदल ──┤
व्यापारातील बदल ─┼──> मोठ्या नागरी केंद्रांचे रूपांतर
पर्यावरणीय ताण ─┤     व प्रादेशिक वस्तींचा विस्तार
सामाजिक बदल ────┘
```

एकच कारण संपूर्ण संस्कृतीच्या परिवर्तनाचे स्पष्टीकरण देत नाही.
