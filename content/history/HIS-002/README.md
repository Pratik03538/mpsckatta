# HIS-002 — सिंधू संस्कृती (हडप्पा संस्कृती)

## अभ्यास उद्दिष्टे
या घटकात सिंधू/हडप्पा संस्कृतीचा कालक्रम, भौगोलिक विस्तार, नगररचना, अर्थव्यवस्था, सामाजिक-सांस्कृतिक जीवन, धार्मिक संकेत, लिपी, व्यापार, प्रमुख स्थळे आणि ऱ्हासाविषयीच्या मांडण्या अभ्यासल्या जातील.

## अभ्यासक्रम
1. नामकरण, शोध व कालविभाग
2. भौगोलिक विस्तार आणि प्रमुख स्थळे
3. नगररचना, बांधकाम व जलव्यवस्थापन
4. शेती, पशुपालन, हस्तव्यवसाय व व्यापार
5. समाज, कला, धर्मविषयक पुरावे व लिपी
6. प्रादेशिक वैशिष्ट्ये आणि उत्तरहडप्पा टप्पा
7. ऱ्हासाचे बहुकारणी स्पष्टीकरण
