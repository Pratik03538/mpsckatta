# HIS-009 — Quick Recall : मौर्योत्तर राजवंश

## 1. मोठे चित्र
मौर्य सत्तेच्या ऱ्हासानंतर भारतात एकाच वेळी अनेक प्रादेशिक व मध्य आशियाई सत्तांचा विकास झाला. उत्तर भारतात शुंग-कण्व, कलिंगमध्ये खारवेल, वायव्येत इंडो-ग्रीक/शक/पहलव/कुषाण आणि दख्खनमध्ये सातवाहन यांचा अभ्यास महत्त्वाचा आहे.

## 2. वंश व प्रमुख व्यक्ती

| सत्ता | प्रमुख नावे | स्मरणबिंदू |
|---|---|---|
| शुंग | पुष्यमित्र, अग्निमित्र, वसुमित्र, देवभूती | पुष्यमित्राने बृहद्रथानंतर सत्ता घेतली; देवभूती शेवटचा शासक |
| कण्व | वासुदेव, भूमिमित्र, नारायण, सुशर्मन | वासुदेव संस्थापक; चार शासकांची परंपरा |
| कलिंग | खारवेल | हाथीगुंफा शिलालेख |
| इंडो-ग्रीक | डेमेट्रियस, मेनांडर | यवन; मिलिंदपन्हो; द्विभाषिक नाणी |
| शक/पश्चिम क्षत्रप | भूमक, नहपान, चष्टन, रुद्रदामन | क्षहरात-कर्दमक; जुनागढ लेख |
| पहलव | गोंडोफर्नेस | पार्थियन/इराणी समूह |
| कुषाण | कुजुल कडफिसेस, विम कडफिसेस, कनिष्क | युएझी, पुरुषपुर, गांधार-मथुरा कला |

## 3. स्थळे — काय जोडायचे?
- **बेसनगर/विदिशा:** हेलिओडोरस गरुडध्वज स्तंभ व वासुदेव भक्ती.
- **अयोध्या:** धनदेव लेख; पुष्यमित्राच्या अश्वमेधाचा उल्लेख.
- **हाथीगुंफा:** खारवेलचा लेख.
- **साकल:** मेनांडरशी संबंधित केंद्र.
- **जुनागढ:** रुद्रदामनचा संस्कृत गद्य लेख व सुदर्शन तलाव.
- **पुरुषपुर:** कुषाणांचे प्रमुख केंद्र; आजचे पेशावर.

## 4. लक्षात ठेवण्यासारखे स्रोत
- साहित्य: महाभाष्य, मालविकाग्निमित्रम्, हर्षचरित, मिलिंदपन्हो, पुराणे.
- अभिलेख: अयोध्या, बेसनगर, हाथीगुंफा, जुनागढ.
- नाणी: इंडो-ग्रीक द्विभाषिक नाणी; शक-कुषाण नाणी व राजप्रतिमा.
- पुरातत्त्व: भरहूत, सांची, तक्षशिला, मथुरा.

## 5. परीक्षेतील गोंधळ टाळा
- यवन = भारतीय स्रोतांत ग्रीकांसाठी वापरली जाणारी संज्ञा; प्रत्येक यवन उल्लेख एकाच राजाला लागू होत नाही.
- शुंग काळात बौद्ध स्मारकांचा विकासही सुरू राहिला; धार्मिक संघर्षाचा सरसकट निष्कर्ष काढू नका.
- हेलिओडोरस हा अँटिअल्किडासचा राजदूत; स्तंभ वासुदेवाशी संबंधित.
- रुद्रदामनचा लेख संस्कृत गद्याचा महत्त्वाचा नमुना; तो सुदर्शन तलावाच्या दुरुस्तीशी संबंधित.
- कनिष्काचा शक संवताशी संबंध परंपरेने जोडला जातो; अचूक कालसंबंध वादग्रस्त आहे.

## 6. स्वतःची 60-सेकंद उजळणी
शुंग → कण्व → प्रादेशिक राज्ये; मेनांडर → नागसेन; नहपान → गौतमीपुत्र; रुद्रदामन → जुनागढ; गोंडोफर्नेस → पहलव; कनिष्क → कुषाण, गांधार-मथुरा.
