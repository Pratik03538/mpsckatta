# HIS-007 — दृश्य उजळणी

## मौर्य राजवंशाची कालानुक्रमिक रूपरेषा
चंद्रगुप्त मौर्य → बिंदुसार → अशोक → उत्तरकालीन मौर्य शासक

## प्रशासनाचे प्रमुख स्तर
सम्राट / केंद्रीय सत्ता → प्रांतीय प्रशासन → जिल्हा व स्थानिक अधिकारी → ग्रामस्तर

| घटक | मुख्य मुद्दा |
|---|---|
| राजधानी | पाटलीपुत्र |
| प्रमुख स्रोत | अर्थशास्त्र, मेगॅस्थेनीजचे वृत्तांत, अशोकाचे शिलालेख |
| चंद्रगुप्त | साम्राज्याची स्थापना; चाणक्याशी परंपरागत संबंध |
| बिंदुसार | साम्राज्याचा पुढील विस्तार व स्थैर्य |
| अशोक | कलिंग युद्धानंतर धम्मधोरणाचा प्रसार |
| ऱ्हास | उत्तराधिकारातील दुर्बलता, प्रादेशिक स्वायत्तता व इतर घटक |

**स्रोतचिकित्सा:** अर्थशास्त्राचा अंतिम ग्रंथरूप काल व मेगॅस्थेनीजच्या वृत्तांताचे उपलब्ध स्वरूप यांबाबत अभ्यासक चर्चा करतात.
