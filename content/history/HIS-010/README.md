# HIS-010 — सातवाहन राजवंश

या topic folder मध्ये MPSC विद्यार्थ्यांसाठी सविस्तर मराठी नोट्स, 50 सराव MCQ, स्वतंत्र topic test, answer key, flashcards, quick recall, visuals आणि PYQ verification register आहे.

## फाइल सूची
- `detailed_notes.md` — सविस्तर विद्यार्थी धडा.
- `practice_mcqs.md` / `practice_mcqs.json` — 50 authored practice MCQs.
- `topic_test.md` — 50 प्रश्नांची test paper (उत्तर न दाखवता).
- `topic_test_answer_key.md` — उत्तर व स्पष्टीकरण.
- `topic_test.json` — test engine / bot साठी डेटा.
- `flashcards.md` — 30 active-recall cards.
- `quick_recall.md` — झटपट पुनरावृत्ती.
- `visuals.md` — तुलना व Mermaid diagrams.
- `pyq.md` / `pyq.json` — PYQ verification status व non-PYQ practice patterns.
- `sources_and_further_reading.md` — संदर्भ व पुढील वाचन.
- `quality_report.md` — सामग्रीची स्थिती व मर्यादा.

**सूचना:** MCQ हे authored practice आहेत; अधिकृत PYQ नाहीत. PYQ म्हणून पाठवण्यापूर्वी मूळ प्रश्नपत्रिका आणि अधिकृत final answer key दोन्ही तपासा.
