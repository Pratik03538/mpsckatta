# HIS-010 — Quick Recall : सातवाहन राजवंश

## 1. मोठे चित्र
सातवाहनांनी मौर्योत्तर काळात दख्खनमध्ये महत्त्वाची प्रादेशिक सत्ता उभारली. त्यांच्या इतिहासात पश्चिम दख्खन, आंध्र प्रदेश, घाटमार्ग, व्यापारी बंदरे, बौद्ध गुंफा, प्राकृत साहित्य आणि वैदिक यज्ञपरंपरा यांचा संगम दिसतो.

## 2. महत्त्वाचे शासक

| शासक/व्यक्ती | मुख्य मुद्दा |
|---|---|
| सिमुक | परंपरेनुसार संस्थापक; कालक्रम व मूळ प्रदेश वादग्रस्त |
| कृष्ण/कान्ह | नाशिक गुंफा लेखाशी संबंधित |
| सातकर्णी प्रथम | नाणेघाट लेख; राणी नागनिका; वैदिक यज्ञ |
| गौतमीपुत्र सातकर्णी | नहपानाचा पराभव; नाशिक प्रशस्ती |
| गौतमी बलश्री | गौतमीपुत्राची माता; नाशिक प्रशस्ती |
| वशिष्ठीपुत्र पुलुमावी | गौतमीपुत्रानंतरचा महत्त्वाचा शासक |
| यज्ञश्री सातकर्णी | काही नाण्यांवरील जहाजाचे चिन्ह; उत्तरकालीन शक्ती |
| हाला | गाथासप्तशतीशी परंपरागत संबंध |

## 3. महत्त्वाचे स्थळे
- **प्रतिष्ठान/पैठण:** पश्चिम दख्खनचे राजकीय व व्यापारी केंद्र.
- **नाणेघाट:** कोकण-दख्खन मार्ग; नागनिका लेख.
- **नाशिक/पांडवलेणी:** कृष्ण, गौतमीपुत्र व गौतमी बलश्रीचे लेख.
- **जोगलथेंबी:** नहपानाची पुनर्मुद्रित नाणी.
- **कार्ले:** प्रसिद्ध बौद्ध चैत्यगृह.
- **अमरावती:** बौद्ध स्तूप व शिल्पपरंपरा.

## 4. स्रोत

| स्रोत | काय समजते? |
|---|---|
| पुराणे | राजसूची व कालावधी; परस्पर विसंगती संभवते |
| नाणेघाट लेख | नागनिका, सातकर्णी प्रथम, यज्ञ व दान |
| नाशिक लेख | राजकीय कामगिरी, वंश, दान |
| नाणी | राजांची नावे, अर्थव्यवस्था, प्रदेश व व्यापार |
| Periplus | पश्चिम किनाऱ्यावरील बंदरे व सागरी व्यापार |
| गाथासप्तशती | महाराष्ट्री प्राकृत साहित्यपरंपरा |

## 5. अर्थव्यवस्था व समाज
- शेती, नदीखोरे, अंतर्गत व्यापारी मार्ग व सागरी बंदरे महत्त्वाची.
- श्रेणी म्हणजे व्यापारी/कारागीर संघटना.
- नाण्यांत शिसे, तांबे, पोटिन आणि काही चांदीची नाणी.
- मातृनामाचा वापर दिसतो; पण त्यावरून संपूर्ण समाज मातृसत्ताक होता असे सिद्ध होत नाही.

## 6. परीक्षा-ट्रॅप्स
- सिमुकचा अचूक कालखंड निश्चित नाही; साधारण कालमान वापरा.
- सातवाहन-आंध्र ओळख आणि मूळ प्रदेशावर इतिहासकारांत मतभेद आहेत.
- गौतमीपुत्राने नहपानाचा पराभव केला; रुद्रदामनने नंतर सातवाहन शासकाचा पराभव केला.
- नाणेघाट लेख नागनिकेचा; नाशिक प्रशस्ती गौतमी बलश्रीशी संबंधित.
- मातृनाम म्हणजे मातृसत्ता असा थेट निष्कर्ष काढू नका.

## 7. स्वतःची 60-सेकंद उजळणी
