# HIS-004 — Visual Revision : महाजनपदे व मगध

## 1. दुसऱ्या नागरीकरणाची कारणसाखळी

```text
शेतीचा विस्तार + लोखंडी साधने + उत्पादनातील अधिशेष
                         ↓
             कारागिरी व देवाणघेवाण
                         ↓
           व्यापारी मार्ग + नाणी + नगरविकास
                         ↓
              मोठी प्रदेशाधारित राज्ये
                    (महाजनपदे)
```

## 2. सोळा महाजनपदे — स्मरणतक्ता

| प्रदेश/संकेत | महाजनपदे | लक्षात ठेवण्याची केंद्रे |
|---|---|---|
| पूर्व | अंग, मगध | चंपा, राजगृह/पाटलीपुत्र |
| मध्य गंगा | काशी, कोसल, वज्जी, मल्ल | वाराणसी, श्रावस्ती, वैशाली, कुशीनारा |
| मध्य भारत | चेदि, वत्स | कौशांबी (वत्स) |
| उत्तर | कुरु, पांचाल | कुरुक्षेत्र परिसर; अहिच्छत्र/कांपिल्य |
| पश्चिम | मत्स्य, शूरसेन, अवंती | विराटनगर, मथुरा, उज्जयिनी |
| उत्तर-पश्चिम | गांधार, कंबोज | तक्षशिला; सीमाभाग |
| दक्षिण | अश्मक | गोदावरी खोरे |

## 3. राजेशाही व गण-संघ

| राजेशाही | गण-संघ |
|---|---|
| वंशपरंपरागत राजा | अनेक प्रमुख/कुळसमूहांची संस्था |
| मगध, कोसल, अवंती, वत्स | वज्जी, मल्ल यांची उदाहरणे |
| कर, सैन्य, अधिकारी व राजदरबार | सभा व सामूहिक निर्णयप्रक्रिया |
| आधुनिक राजेशाहीशी तुलना करतानाही काळभेद लक्षात घ्या | आधुनिक सार्वत्रिक लोकशाही समजू नका |

## 4. मगधचा उदय : सात घटक

```text
सुपीक गंगा खोरे ─┐
लोखंड व वनसंपत्ती ┤
हत्ती व सैन्य     ├──> संसाधनांचा आधार
नदीमार्ग          ┘
       +
राजगृहाची संरक्षणक्षमता → पाटलीपुत्राचे संपर्कस्थान
       +
बिंबिसार/अजातशत्रू/उदायिन यांचे धोरण
       ↓
मगधचे राजकीय व लष्करी बळकटीकरण
```

## 5. राजवंशांचा व्यापक क्रम

| वंश/टप्पा | प्रमुख शासक | लक्षात ठेवण्याचा मुद्दा |
|---|---|---|
| हर्यंक | बिंबिसार, अजातशत्रू | विवाहसंबंध, अंगविजय, वज्जी संघर्ष |
| संक्रमण | उदायिन | पाटलीपुत्राशी संबंध |
| शिशुनाग | शिशुनाग, कालाशोक (परंपरा) | अवंतीच्या समावेशाशी संबंध |
| नंद | महापद्म नंद, धनानंद | मौर्यपूर्व शक्तिशाली सत्ता |
| पुढे | चंद्रगुप्त मौर्य | मौर्य साम्राज्याची स्थापना |

## 6. स्थळ-राज्य जुळवा

- अंग — चंपा
- मगध — राजगृह; पुढे पाटलीपुत्र
- काशी — वाराणसी
- कोसल — श्रावस्ती
- वज्जी — वैशाली
- वत्स — कौशांबी
- शूरसेन — मथुरा
- अवंती — उज्जयिनी
- गांधार — तक्षशिला
- अश्मक — गोदावरी खोरे

## 7. स्रोतचिकित्सा

| स्रोत | काय सांगतो | काळजी |
|---|---|---|
| अंगुत्तर निकाय | सोळा महाजनपदांची यादी | जैन यादीत फरक |
| भगवती सूत्र | जैन परंपरेतील राज्यांची नावे | यादी तंतोतंत जुळत नाही |
| पुरातत्त्व | वस्ती, तटबंदी, नाणी, उत्पादन | राजकीय सीमा थेट ठरत नाहीत |
| नंतरचे वृत्तांत | राजवंश व युद्धकथा | कालांतर व साहित्यिक हेतू तपासा |
