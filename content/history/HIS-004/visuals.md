# HIS-004 — दृश्य उजळणी

## सोळा महाजनपदे
| गट / प्रदेश संकेत | महाजनपदे |
|---|---|
| गंगा खोऱ्यातील प्रमुख राज्ये | अंग, मगध, काशी, कोसल |
| गणसंघ परंपरा | वज्जी, मल्ल |
| मध्य व उत्तर भारत | चेदि, वत्स, कुरु, पांचाल, मत्स्य, शूरसेन |
| पश्चिम व उत्तर-पश्चिम | अवंती, गांधार, कंबोज |
| दक्षिणेकडील महाजनपद | अश्मक |

## महत्त्वाची केंद्रे
| महाजनपद | केंद्र |
|---|---|
| मगध | राजगृह; पुढे पाटलीपुत्र |
| वज्जी | वैशाली |
| वत्स | कौशांबी |
| कोसल | श्रावस्ती |
| अवंती | उज्जयिनी व माहिष्मती |
| मल्ल | कुशीनगर व पावा |

## मगधच्या उदयाची कारणसाखळी
सुपीक गंगा खोरे + लोखंडी साधने + हत्ती + नदीमार्ग  
↓  
शेती, उत्पादन, वाहतूक व व्यापारात वाढ  
↓  
महसूल आणि सैन्य उभारणीची क्षमता  
↓  
शासकांचे युद्ध व राजनैतिक धोरण  
↓  
मगधचे प्रादेशिक वर्चस्व

## साधारण राजकीय कालरेषा
महाजनपदांचा उत्कर्ष → हर्यंक (बिंबिसार, अजातशत्रू, उदायिन) → शिशुनाग → नंद → मौर्य सत्तेचा उदय.

## राजेशाही व गणसंघ
| राजेशाही | गणसंघ |
|---|---|
| सत्ता राजाकडे केंद्रित | प्रमुखांच्या सभेकडे / गणाकडे सत्ता |
| उदाहरणे: मगध, कोसल | उदाहरणे: वज्जी, मल्ल |

**स्रोतचिकित्सा:** साहित्यिक यादी व राजकीय वृत्तांत पुरातत्त्वीय पुराव्यांशी तुलना करून समजावेत. कालमर्यादा अंदाजे आहेत.
