# HIS-003 — दृश्याधारित अभ्यास

## 1. वैदिक साहित्याची रचना

```text
                 वैदिक साहित्य
                       │
          ┌────────────┴────────────┐
          │                         │
       संहिता                   पुढील साहित्य
                                  │
                    ┌─────────────┼─────────────┐
                 ब्राह्मणे       आरण्यके       उपनिषदे
                 यज्ञविधी       चिंतन          तत्त्वज्ञान
```

## 2. चार वेद — झटपट जुळणी

| वेद | मुख्य ओळख |
|---|---|
| ऋग्वेद | स्तोत्रे; सर्वात प्राचीन |
| सामवेद | गायन |
| यजुर्वेद | यज्ञविधी |
| अथर्ववेद | दैनंदिन जीवन, आरोग्य, संरक्षणाशी संबंधित मंत्र |

## 3. प्रारंभिक ते उत्तर वैदिक परिवर्तन

```text
प्रारंभिक/ऋग्वेदीय टप्पा
पशुपालन महत्त्वाचे • गो-संपत्ती • सभा-समिती
इंद्र-अग्नी-वरुण उपासना
             │
             ▼
उत्तर वैदिक टप्पा
कृषीविस्तार • लोखंडाचा वाढता वापर
जनपदांचा विकास • वर्णविभागणी अधिक श्रेणीबद्ध
```

## 4. वैदिक राजकीय संस्था

| संज्ञा | साधारण संदर्भ |
|---|---|
| राजन् | जनसमूहाचा प्रमुख |
| सभा | निवडक/प्रतिष्ठित सदस्यांची परिषद असा अर्थ |
| समिती | व्यापक सामुदायिक सभा असा अर्थ |
| विदथ | सामुदायिक, धार्मिक किंवा आर्थिक कार्यांशी संबंधित संस्था |

संस्थांचे स्वरूप व अधिकार यांबाबत ग्रंथसंदर्भांचे अर्थ लावताना सावधगिरी आवश्यक.

## 5. देवता — स्मरण नकाशा

- इंद्र → वज्र, युद्ध, वृत्रवध.
- अग्नी → यज्ञाग्नी, देव-मानव मध्यस्थ.
- वरुण → ऋत/विश्वव्यवस्था.
- सोम → देवता व यज्ञातील सोम.
- उषा → पहाट.
- सूर्य/सविता → सूर्यप्रकाश व प्रेरणा.

## 6. सामाजिक परिवर्तन

```text
कृषी व स्थिर वस्तीचा विस्तार
          +
लोखंडी साधनांचा वाढता वापर
          +
उत्पादन व संसाधनांवरील नियंत्रण
          ↓
मोठे जनसमूह/जनपद आणि सामाजिक स्तरभेदांचे संकेत
```

## 7. परीक्षेतील सावधगिरी
- वैदिक साहित्याला आधुनिक इतिहासवृत्त समजू नये.
- ग्रंथातील आदर्श विधान व प्रत्यक्ष सामाजिक व्यवहार वेगळे असू शकतात.
- प्रारंभिक समाज फक्त पशुपालक नव्हता; शेतीचेही संदर्भ आहेत.
- वर्णव्यवस्थेचे उत्तरकालीन स्वरूप थेट प्रारंभिक काळावर लादू नये.
