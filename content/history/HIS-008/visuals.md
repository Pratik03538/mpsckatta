# HIS-008 — Visual Revision Pack : अशोकाचे धम्म व शिलालेख

## 1. कलिंग ते धम्मविजय

```text
कलिंग युद्ध
   ↓
युद्धहानी व खेद
   ↓
तेरावा प्रमुख शिलालेख
   ↓
धम्मविजय व प्रजाहित
```

## 2. धम्माचे मुख्य घटक

| मूल्य | व्यवहारातील उदाहरण |
|---|---|
| आदर | माता-पिता, गुरु व वडीलधारी |
| दया | मानव व प्राण्यांविषयी सहानुभूती |
| सहिष्णुता | इतर पंथांचा आदर |
| संयम | अनावश्यक विधी व हिंसा कमी करणे |
| कल्याण | आरोग्य व सार्वजनिक सुविधा |

## 3. महत्त्वाचे प्रमुख शिलालेख

| क्रमांक | मुख्य मुद्दा |
|---|---|
| I | प्राणिहिंसेवर मर्यादा |
| II | मानव/प्राणी आरोग्य उपाय |
| V | धम्ममहामात्र |
| VIII | धम्मयात्रा |
| XII | धार्मिक सहिष्णुता |
| XIII | कलिंग युद्ध, पश्चात्ताप व धम्मविजय |

## 4. लेखांचे प्रकार

| प्रकार | माध्यम |
|---|---|
| प्रमुख शिलालेख | खडक |
| लघु शिलालेख | खडक/शिलापृष्ठ |
| प्रमुख स्तंभलेख | दगडी स्तंभ |
| लघु स्तंभलेख | विशिष्ट स्तंभ/स्थळ |
| गुहालेख | गुहेतील दान/नोंद |
| स्वतंत्र कलिंग लेख | धौली, जौगड |

## 5. भाषा व लिपी

| प्रदेश | भाषा/लिपी |
|---|---|
| बहुतांश लेख | प्राकृत + ब्राह्मी |
| उत्तर-पश्चिम | प्राकृत रूपे + खरोष्ठी |
| कंधार | ग्रीक व अरामाइक |

## 6. स्थळे व ओळख

| स्थळ | ओळख |
|---|---|
| गिरनार | गुजरात |
| धौली | ओडिशा; स्वतंत्र कलिंग लेख |
| जौगड | ओडिशा; स्वतंत्र कलिंग लेख |
| शाहबाजगढी | खरोष्ठी |
| मानसेहरा | खरोष्ठी |
| कंधार | ग्रीक-अरामाइक |
| सोपारा | महाराष्ट्र |
| सारनाथ | सिंहशीर्ष |
| बाराबर | आजीवक गुहा |

## 7. स्रोत व मर्यादा

```text
अशोकलेख = समकालीन राजकीय संदेश
             ↓
धम्म / अधिकारी / साम्राज्य / भाषा
             ↓
पुरातत्त्व + नाणी + साहित्य यांच्याशी तुलना
             ↓
संतुलित ऐतिहासिक निष्कर्ष
```
